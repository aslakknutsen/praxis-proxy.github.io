Praxis projects are documented and released independently. This manifest links
each project's current default release. Archived releases and the unreleased
development channel remain available from each page's version selector; they
are not listed here, and matching version numbers across projects do not imply
tested compatibility.

Every link points to a Markdown version when one exists, otherwise to the HTML
page. The full URL inventory is in [sitemap.xml]({{ "sitemap.xml" | absURL }}).
